# Reflection · Requiro

## Hardest part

The hardest part was the metrics: deciding how to measure success and get
consistent results when an LLM can answer the same request differently on
different attempts.

## What I will keep doing

I want to define the expected behavior and minimum passing scores before judging
an assistant reply. For Requiro, that means checking the same fictional requests
repeatedly, using the same rubric, and counting correction time as part of the
work. The metrics plan sets out this next step; the experiment has not yet run.

## What changed my thinking

Consistency means that each answer meets the same requirements, even when the
wording changes. My role as a product manager is to define acceptable behavior,
the evidence needed to judge it, and when a human must decide.
